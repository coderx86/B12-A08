
# HeroIO - Productive App Store

HeroIO is a modern, responsive web application designed to showcase and simulate the installation of productivity applications. Users can browse a curated list of apps, view detailed statistics including ratings and reviews, and manage their installed applications locally.

## Features

- **Home Page**: Dynamic banner, statistics, and trending apps.
- **Browse Apps**: Live search and sorting functionality to find apps easily.
- **App Details**: In-depth view with charts, description, and installation simulation.
- **My Installation**: meaningful management of installed apps using LocalStorage.
- **Responsive Design**: Optimized for all devices using Tailwind CSS.

## Technologies Used

* **React**: Component-based UI library.
* **Vite**: Next Generation Frontend Tooling.
* **Tailwind CSS**: Utility-first CSS framework for styling.
* **daisyUI**: Tailwind CSS component library for prebuilt UI components and themes.
* **React Router**: For seamless client-side navigation.
* **Recharts**: For data visualization (Review charts).
* **React Toastify**: For notification toasts.
* **React Icons**: For beautiful vector icons.
* **LocalStorage**: For persisting installed app data.

## Getting Started

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
4. Open your browser and navigate to the local server URL.
